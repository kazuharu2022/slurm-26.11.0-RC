[AveCPU sentinel diagnosis]

src/common/slurmdb_defs.c:4379-4401 returns INFINITE64 when the TRES string or
the requested TRES ID is absent.
src/sstat/print.c:129-136 rejects NO_VAL64 but not INFINITE64, divides the
returned value by CPU_TIME_ADJ=1000, then formats it as elapsed time.

(2^64 - 1) / 1000 = 18446744073709551 seconds
18446744073709551 seconds = 213503982334 days 14:25:51

measured CPU usage.
