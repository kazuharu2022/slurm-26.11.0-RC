ROOT CAUSE CORRECTION
`run_command()` invokes `_run_command_child_pre_exec()`, which unconditionally
closes every descriptor from 3 upward before executing the target. Therefore an
embedded script path such as `/dev/fd/6` cannot be inherited by `/bin/sh`.
The earlier `/bin/sh /dev/fd/3` successes depended on incidental descriptor
reuse and did not prove a stable execution contract. The previous production
client-only PASS is retained as observed history but is superseded as a
non-deterministic false positive.
