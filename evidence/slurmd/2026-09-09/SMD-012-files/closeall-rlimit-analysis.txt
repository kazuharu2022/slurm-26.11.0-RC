Common source path
==================

- src/slurmd/slurmd/slurmd.c::_try_to_reconfig() calls
  closeall_except(3, close_skip) immediately before execve().
- src/slurmd/slurmd/req.c::_forkexec_slurmstepd() calls closeall(3)
  immediately before execvp(slurmstepd).
- src/common/fd.c uses close_range() when available. macOS does not expose
  close_range(), so the fallback calls close(fd) for every descriptor number
  below rlimit_nofile.
- When RLIMIT_NOFILE is RLIM_INFINITY, the original fallback calls
  sysconf(_SC_OPEN_MAX), casts it to int, and maps -1 to INT_MAX.

Source correction
=================

On macOS, when RLIMIT_NOFILE is infinite or does not fit in int,
closeall_init() now reads kern.maxfilesperproc via sysctlbyname(). The sysctl
call occurs during process startup, before any post-fork closeall() call. A
finite representable RLIMIT_NOFILE keeps the existing behavior. Other systems
retain the sysconf fallback.

Fixed-loop probe under an explicitly unlimited soft limit:

rlimit_nofile=9223372036854775807 kern.maxfilesperproc=245760 close_calls=245757 closed=0 ebadf=245757 elapsed_seconds=0.037036
