# SMD-003 stdout・stderr・exit code — 試験計画とEvidence

## 判定

- 日時: 2026-09-09 16:46–16:50 JST
- 状態: `PASS_STAGING`
- 前提: SMD-001、SMD-002はstaging構成で `PASS_STAGING`
- 対象: 非対話taskのstdout、stderr、process exit code、client return code、
  accounting上のjob/step ExitCode

## Research Question

macOS上の `slurmd` / `slurmstepd` は、taskがstdoutとstderrへ書いた内容を混同せず
clientへ転送し、exit 0・1・255をclientとSlurmDBDへ欠落なく伝えられるか。

## 比較条件

独立変数はtaskのexit code（0、1、255）。各taskは対応するcodeを文字列として
stdoutとstderrへ1行ずつ出力する。node、user、task数、command、time limit、
working directory、staging binary/configは固定する。

## artifact

```text
source=contribs/macos-tests/smd003_stdio_exit.sh
staging=/tmp/slurm-smd001-fixed/smd003_stdio_exit.sh
sha256=1e46d9014a58ca3645a6d9dc68a630bb712d5eb82626b41275511d6decd148fe
syntax_check=/bin/sh -n (exit 0)
```

scriptは各caseを独立した `srun` jobとして投入し、次を保存する。

```text
/tmp/slurm-smd003-<timestamp>/exit-<code>.out
/tmp/slurm-smd003-<timestamp>/exit-<code>.err
/tmp/slurm-smd003-<timestamp>/exit-<code>.client-rc
```

## 実行方法

Macの `testuser` sessionで実行する。

```bash
/tmp/slurm-smd001-fixed/smd003_stdio_exit.sh
```

script末尾に表示される `run_dir` と全出力を保存する。実行後、controller/database
側の `sacct`、queue、node状態、worker上の残留processを別途照合する。

## 成功条件

1. exit 0のstdoutは `stdout_marker=exit_0`、stderrは
   `stderr_marker=exit_0` を含む。
2. exit 1、255も、それぞれ対応するmarkerをstdout/stderrへ保持する。
3. `.client-rc` はそれぞれ0、1、255になる。
4. `sacct` の各job/step ExitCodeはそれぞれ `0:0`、`1:0`、`255:0` になる。
5. exit 0は`COMPLETED`、exit 1と255は失敗を表すstateとなる。
6. queue、allocation、task processが残らず、PC-210がIDLEへ復帰する。

stderrにはtask markerに加えて、非0終了を報告する `srun` 自身のdiagnosticが入る
可能性がある。markerが正しいstreamに存在することと、混入内容を分けて記録する。

## 分析と判定

- 3条件すべてでstdout markerとstderr markerが正しいfileへ分離された。
- exit 1/255のstderrにはmarkerに加え、`srun` の非0終了diagnosticが記録された。
  これはstream混同ではなくclient自身のstderrである。
- client rc、job ExitCode、step ExitCodeは0、1、255ですべて一致した。
- stateはexit 0が`COMPLETED`、非0の2件が`FAILED`となった。
- resourceとprocessのcleanupも完了した。

成功条件をすべて満たしたため、SMD-003を `PASS_STAGING` とする。追加source修正は
不要だった。production install前のstaging binary/configによる結果である。
