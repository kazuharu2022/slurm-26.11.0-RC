- Homebrew Open MPI dependencies include gcc 16.2.0, hwloc 2.14.0,
  libevent 2.1.13, PMIx 6.1.0, and PRRTE 4.1.0.
- Homebrew Open MPI conflicts with Homebrew MPICH because both install MPI wrappers.
- Homebrew MPICH stable: 5.0.1; the formula does not list PMIx or PRRTE as dependencies.

Decision
========
1. Recommend Open MPI rather than MPICH for the next macOS-only phase.
   The Homebrew Open MPI dependency graph directly matches the already verified
   PMIx 6.1.0/libevent 2.1.13/hwloc 2.14.0 stack. The stock MPICH formula does
   not establish the PMIx linkage required for the current direct-launch goal.
2. The next bounded action is installation of Homebrew Open MPI 5.0.11 on PC-210,
   followed only by version/linkage/compiler-wrapper readback. It must not include
   a Slurm job, daemon restart, Slurm configuration change, or Ubuntu installation.
3. This native MPI implementation cannot be installed through a Python uv
   environment. Homebrew is therefore a documented native-toolchain exception to
   the repository's uv rule and requires explicit approval before host mutation.
4. Multi-node MPI is not approved or ready:
   - Ubuntu's stock Open MPI candidate is 4.1.6 while macOS Homebrew provides 5.0.11.
   - Open MPI documents that a single MPI job is only guaranteed when exactly the
     same Open MPI version is used everywhere.
   - Ubuntu's installed Slurm client/plugin set has no PMIx plugin, so Open MPI 5
     direct launch with srun --mpi=pmix is not currently available from that stack.
   - A later multi-node phase needs an exact-version Open MPI build/install plan on
     both architectures and a separate choice between mpirun-in-allocation and
     Slurm PMIx direct launch.
