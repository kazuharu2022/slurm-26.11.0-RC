   PMIx results had already succeeded. `brew list prrte` showed the provided
   executable is `prte`; `prte --version` then returned PRRTE 4.1.0.
2. `brew linkage --test open-mpi` warned that it automatically enabled Homebrew
   developer mode. This was an unintended diagnostic side effect. It was
   immediately reverted with `brew developer off`; subsequent `brew config`
   did not report developer mode. MPI/Slurm artifacts were not changed by the
   restoration.

   independent `brew missing open-mpi` check exited 0.
